¿Cuál fue la diferencia principal que notaste entre for y while?
¿Te pareció útil el uso de break y continue? ¿Por qué?

Diferencia entre for y while:

La principal diferencia es que el ciclo for se usa cuando ya se sabe cuantas veces se va a repetir algo, como recorrer una lista o un rango.
El ciclo while en cambio se usa cuando no se sabe exactamente cuantas veces se repetira, ya que depende de una condicion que se evalua constantemente.

Sobre break y continue:
Si, son utiles.
break   : permite salir inmediatamente de un ciclo, lo que sirve para detener ejecuciones cuando ya no son necesarias.
continue: permite saltarse una iteracion especifica sin detener todo el ciclo, lo que ayuda a filtrar casos sin cortar el flujo completo.
